**Personal genealogy research tools and specialized reporting commands**

This extension provides advanced genealogy research tools for working with personal family databases, including:

- **Census Records**: Federal census data analysis and reporting
- **FindAGrave Integration**: Tools for managing FindAGrave memorial data
- **Obituary Management**: Newspaper obituary tracking and summarization  
- **Source Analysis**: Advanced source citation and newspaper source management
- **Tabulation Reports**: Specialized reports for source organization and analysis

Designed for serious genealogy researchers working with their personal RootsMagic databases containing real family history data.

**Important Note**: These capabilities are highly dependent on the format and structure of the data inputted into RootsMagic. The tools expect specific naming conventions, source formats, and data organization patterns to function properly.
